# Fonts Setup

## Google Fonts
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600;700&display=swap" rel="stylesheet">
```

## Flutter (pubspec.yaml)
```yaml
dependencies:
  google_fonts: ^6.0.0
```

## Usage
| Role | Font | Weight |
|------|------|--------|
| Headings (h1-h6) | Space Grotesk | 600 (semibold) |
| Body text | Inter | 400 (regular) |
| UI labels, buttons | Inter | 500 (medium) |
| Code, mono | JetBrains Mono | 400 (regular) |
