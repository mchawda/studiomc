# Shell — Studiomc

## Pattern
Sidebar (ChatGPT-style)

## Layout
- **Left sidebar** (280px, collapsible): New Chat button, conversation list (grouped), Documents nav, Settings gear
- **Center**: main content area (flexible width)
- **Right panel** (320px, toggleable): context panel (model info / sources / trace)

## Top Bar
- Model indicator (name + speed rating badge)
- Mode selector: segmented control (Chat / Docs / Investigate)
- Theme toggle (light/dark)

## Responsive
- Desktop: sidebar always visible
- Tablet (<1024px): sidebar collapses via hamburger
- Mobile (<768px): drawer overlay + bottom tab bar

## Screens
1. Home/Chat — conversation + messages
2. Documents — library + collections
3. Models — recommended + installed + discover
4. Performance — speed rating + metrics
5. Settings — privacy + appearance + advanced
