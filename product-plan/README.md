# Studiomc — Implementation Package

## What This Is
Complete implementation package for Studiomc, a local AI desktop app. Generated by DesignOS from the product blueprint.

## Quick Start

### One-Shot (full build in one session)
1. Give your coding agent `prompts/one-shot-prompt.md`
2. Attach `instructions/one-shot-instructions.md` + `product-overview.md`

### Incremental (milestone by milestone)
1. Give your coding agent `prompts/section-prompt.md`
2. Work through `instructions/incremental/` in order (01 → 09)

## Tech Stack
- **App:** Flutter (Dart) — macOS, Windows, iOS, Android
- **Services:** Python 3.11+, FastAPI, WebSockets, AirLLM
- **Storage:** SQLite + filesystem
- **Intelligence:** CLaRa RAG, Local Reasoning Environment
